# راهنمای کاربری

[بازگشت به معرفی پروژه](../README.md)

## مطالعهٔ ترجمه‌ها

مسیر `/` صفحهٔ Word Translations است. زبان را از فهرست انتخاب کنید. کارت‌ها ترتیب تعیین‌شده در مدیریت را رعایت می‌کنند؛ عنوان واژه روی کارت با حروف کوچک نمایش داده می‌شود. نبودن ترجمه با `No translation yet` مشخص است. رابط انگلیسی می‌ماند؛ متن ترجمه با `lang` و `dir` زبان انتخاب‌شده نمایش داده می‌شود. ناوبری عمومی هنگام اسکرول به بالای صفحه می‌چسبد و عرض آن باز می‌شود.

## ویرایش ترجمه

۱. از پیوند Management Page یا مسیر `/manage` وارد مدیریت شوید.
۲. زبان مقصد را انتخاب کنید.
۳. متن روبه‌روی واژه را تغییر دهید؛ تغییر در state اعمال و سپس کل داده ذخیره می‌شود. دکمهٔ ذخیرهٔ جداگانه وجود ندارد.
۴. برای دیدن نتیجه وارد Public Page شوید.

محدودیت ترجمه ۵۰۰ کاراکتر است. reducer فاصلهٔ ابتدا و انتهای مقدار را حذف می‌کند؛ مقدار خالی از دیکشنری ترجمه حذف می‌شود. تغییر یک زبان به ترجمهٔ زبان‌های دیگر دست نمی‌زند.

کارت‌های آماری Keywords و Languages تعداد واژه و زبان را نشان می‌دهند. **Needs translation بر اساس زبان اول فهرست محاسبه می‌شود، نه لزوماً زبان انتخاب‌شده.**

## افزودن واژه

Add Keyword فرم واژه و فیلد تمام زبان‌های موجود را باز می‌کند. نام واژه ۱ تا ۸۰ کاراکتر و حداقل یک ترجمهٔ غیرخالی لازم است. لازم نیست همهٔ زبان‌ها پر شوند. مقادیر با حذف فاصله‌های ابتدا و انتها ثبت می‌شوند و واژهٔ جدید به انتهای فهرست می‌رود.

یکتایی نام با حذف فاصله، نرمال‌سازی Unicode به NFC و تبدیل به حروف کوچک سنجیده می‌شود؛ بنابراین `Hello` و `hello` تکراری‌اند. شناسهٔ داخلی مستقل از نام است. خطای فرم در همان دیالوگ نمایش داده می‌شود و ورودی نامعتبر می‌تواند فوکوس بگیرد. Cancel، دکمهٔ بستن، Escape یا کلیک روی پس‌زمینهٔ خارج دیالوگ، فرم را بدون افزودن می‌بندند.

## تغییر ترتیب واژه‌ها

دستهٔ کنار واژه را بکشید. با صفحه‌کلید، دسته را با Tab انتخاب کنید، Space بزنید، با کلیدهای جهت‌دار جابه‌جا کنید و با Space رها کنید؛ Escape لغو می‌کند. ترتیب ذخیره می‌شود و در همهٔ زبان‌ها و صفحهٔ عمومی مشترک است.

## مدیریت زبان‌ها

Manage languages فهرست و فرم افزودن زبان را باز می‌کند:

| فیلد           | مقدار                                                                                   |
| -------------- | --------------------------------------------------------------------------------------- |
| Language code  | کد قابل قبول برای `Intl.getCanonicalLocales` مانند de یا pt-BR؛ ورودی حداکثر ۳۵ کاراکتر |
| Language name  | نام نمایشی ۱ تا ۸۰ کاراکتر، مانند Deutsch                                               |
| Text direction | Left to right یا Right to left                                                          |

کد canonical می‌شود؛ برای مثال `AR` همان `ar` است و اگر عربی موجود باشد پذیرفته نمی‌شود. افزودن موفق دیالوگ را می‌بندد و زبان جدید را فعال می‌کند. ترجمهٔ خودکار انجام نمی‌شود؛ واژه‌های قبلی برای آن زبان خالی‌اند.

فلش‌ها ترتیب زبان‌ها در selector را تغییر می‌دهند. زبان اول، زبان شروع پس از reload و مبنای آمار ترجمه‌های ناقص است. حذف زبان به تأیید مرورگر نیاز دارد و ترجمه‌های همان زبان را نیز حذف می‌کند؛ امکان Undo وجود ندارد. آخرین زبان قابل حذف نیست. اگر زبان فعال حذف شود، اولین زبان باقی‌مانده فعال می‌شود.

## ذخیره‌سازی و رفع اشکال

داده به origin مرورگر وابسته است؛ تغییر پروتکل، hostname یا پورت فضای ذخیرهٔ دیگری دارد. مثلاً `localhost` و `127.0.0.1` دادهٔ مشترک ندارند. پاک‌کردن داده‌های سایت، استفاده از پروفایل دیگر یا دستگاه دیگر، داده را منتقل نمی‌کند.

| وضعیت                                 | معنی و اقدام                                                                                          |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| could not be saved                    | تغییرات در همین نشست موجودند؛ قبل از بستن صفحه، محدودیت فضای مرورگر یا تنظیمات storage را بررسی کنید. |
| نمایش starter words پس از خطای خواندن | داده قابل خواندن نبوده؛ جزئیات حفظ نسخهٔ خراب در [مدل داده](data-model.fa.md) آمده است.               |
| تغییر زبان پس از refresh              | انتخاب فعال ذخیره نمی‌شود؛ زبان اول فهرست انتخاب می‌شود.                                              |
| ترجمه در دستگاه دیگر دیده نمی‌شود     | برنامه backend یا انتشار مشترک ندارد.                                                                 |
| 404 هنگام بازکردن مستقیم /manage      | میزبان باید fallback برنامهٔ SPA به index.html داشته باشد.                                            |

قبل از هر بازیابی دستی، مقدار کلید `language-board.dataset` را از بخش Local Storage ابزار توسعهٔ مرورگر کپی کنید. رابط دکمهٔ backup/reset ندارد. حذف کلید برای شروع مجدد، داده را از دسترس برنامه خارج می‌کند؛ فقط پس از تهیهٔ نسخهٔ پشتیبان و با تصمیم آگاهانه انجام شود.
